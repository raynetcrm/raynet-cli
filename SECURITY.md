# Security policy

Report a vulnerability in `raynet` privately through GitHub's
[private vulnerability reporting](https://github.com/raynetcrm/raynet-cli/security/advisories/new)
(the repo's **Security** tab, **Report a vulnerability**). Never report one in a public issue.

Include the `raynet --version` output, the affected command and how to reproduce it, but no real API
keys, bearer tokens or passwords.

`raynet` is an early proof of concept: we respond on a best-effort basis, and fixes ship in the next
release. Only the latest release is supported.
